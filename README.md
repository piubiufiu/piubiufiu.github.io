# 笔记 · 使用说明

单文件网页（`index.html`），样式、脚本、27 篇数据全部内联，零外链、可断网。原文与脚手架以 AES-256-GCM 密文存在文件里，没有口令打不开，源码里搜不到任何篇名或正文。

**一句话上手**：任意设备打开 → 输 `2004` → 点页眉的「同步」按钮对齐进度（不用输频道号）。

- 线上：**https://piubiufiu.github.io/k7m2q/**
- 旧地址：https://piubiufiu.github.io/zzbs/ 已覆盖为同一份文件
- 电脑离线：双击 `index.html`（`file://` 下 WebCrypto 正常）
- 手机离线：把 `index.html` 传到手机用浏览器打开（别用「文件」App 预览）

## 一、口令 2004 与它的真实强度

- **算法**：口令经 PBKDF2-SHA256（150000 次、16 字节随机盐）派生 256 位密钥，AES-256-GCM 加密全部数据（12 字节随机 IV，密文带认证标签）。口令不写进文件，文件里只有盐、IV、密文。
- **归一化**：忽略所有空格与大小写，`2004` 与 `200 4` 等价。
- **错误口令**：只显示「口令错误」，不解密、不推导频道、不发任何网络请求，也不暴露篇名/篇数/字数。
- **强度提示（重要）**：4 位数字只有 0000–9999 共 **1 万种组合**，脚本穷举几十分钟就能试完。它挡得住"随手打开看一眼"，挡不住有意破解的人。
- **改口令**：设置 ⑤ 输入新口令 →「改口令并导出」，浏览器本地重新加密并下载 `note.html`（中性文件名，内容就是新的单文件页面）。旧口令立即失效。要上线就自己把 `note.html` 改名回 `index.html`，覆盖 `k7m2q/index.html` 与 `zzbs/index.html` 两处。
- **锁定**：设置 ⑤「立即锁定」清空内存数据、会话密钥与已派生的频道号，回到锁定页。免重输状态只放 `sessionStorage`（同一标签页、24 小时内有效），关浏览器即失效。
- **忘记口令**：没有后门，忘了就是打不开。请自己妥善保管口令。

## 二、同步：点节点就自动上传，页眉只有一个「同步」按钮

- **自动上传**：点任意 D1…D30 节点、改首背日、改备考日 → 立刻置「待上传」，**1.5 秒去抖后自动 POST**，不用点任何按钮。
- **自动拉取**：打开或刷新页面（解锁后）自动拉一次云端并**并集合并**，然后才渲染。
- **唯一「同步」按钮**（页眉右侧）：点一次 = 再拉一次云端 → 并集合并 → 本机若有未上传改动才补推 → 提示"并入 N 项 / 已上传 / 失败原因"。面板里的「仅上传」「仅下载」已删除。
- **自动同步默认关闭**。打开后每 **5 分钟**静默同步一次（页签在后台时跳过），可随时关掉＝回到纯手动。
- **频道由口令派生**：解锁成功后，页面用 PBKDF2-SHA256（固定盐 `nb-sync-channel-v1`、100000 次）算出口令的频道号（`nb` + 18 位小写字母数字）。口令相同即同一频道，**无需输入频道号**。
- **通道**：ntfy.sh 匿名消息服务，`POST https://ntfy.sh/<频道号>` 推全量进度快照，`GET /<频道号>/raw?poll=1&since=all` 拉取全部历史快照。
- **状态文案（严格，不假绿）**：`已上传` / `待上传` / `已同步(N)` / `离线` / `上传失败`。只有 POST 真的返回成功才出现「已上传 / 已同步」；失败时保持 dirty 并显示「上传失败」。
- **只传进度**：每篇 7 个节点勾选（位掩码）、首背日、开始备考日、设备编号与心跳。**不含原文、不含篇名、不含科目词**。
- **合并规则（pull 把 `since=all` 的每一条快照都并集合并，绝不整体覆盖本机）**：节点任一快照为 1 即为 1（只增不减）；首背日取所有快照里最早的非空值；开始备考日取 `startAt` 最新的显式值；空快照、旧快照不产生任何效果。
- **硬保险（运行时断言）**：每次拉取前拍一张本机勾选快照，合并后若本机勾选数变少，立即回滚并在控制台报 `[同步·断言失败]`。
- **防洗白**：本机为空时绝不 POST（不会把云端洗成默认）；云端有数据而本机为空时以云端为准。
- **可核对**：折叠面板里有「最近一次拉取的云端快照」只读小窗（条数/设备名/时间/掩码/本次并入项数）。
- **取消勾选的取舍（重要）**：合并只增不减，所以取消勾选只在本机生效；下次拉取时云端那条旧勾选可能把它重新勾上。
- **失败退避**：写入被拒时读服务端 `Retry-After`（或按 15s→30s→60s→120s→300s 上限递增）退避重试，不做死循环；手动点「同步」可随时立即重试。自动同步关闭时不自动重试，只显示失败。
- **12 小时保留不丢数据**：每次推送都是全量快照；超过 12 小时没同步，下次点「同步」会再推一次并自动补齐。
- **本地存储按 origin 隔离**：`https://…/k7m2q/`、`https://…/zzbs/`、本地 `file://`、以及用局域网 IP 打开的页面各自一份进度，互不相通（用不同地址打开看起来就像"回到默认"）。

## 三、短码（服务不可用时的兜底）

同一口令在任意设备点一次「同步」即可对齐，平时不用任何码。只有云端连不上、或换设备想离线搬进度时才用短码：

1. 设置 ② →「生成短码」→ 复制 `NB1-XXXXX-XXXXX-XXXXX-XXXXX-XX`。
2. 另一台设备 ③ → 粘贴 → 选「覆盖本机」或「只补未完成的（合并）」→ 导入。
3. 长度不固定：已开始的篇数越多越长（约 30–123 字符），末尾带校验，抄错会直接提示，不会写错数据。
4. 短码只含首背日与节点勾选，不含原文；二维码是折叠的可选项。

## 四、导出进度 / 归档到夸克网盘（只做导出，没有集成）

页面不对接夸克网盘。要归档就自己把导出的文件传上去：

1. 解锁后设置 ② →「**导出进度备份 progress-backup.json**」。
2. 文件内容：`{kind:"progress-backup", enc:"P1:plain", at, payload}`，`payload` 就是同步用的全量进度快照（明文进度，**不含任何正文**），自己注意存放位置。
3. 传到夸克网盘当归档，这一步在网盘客户端里做。
4. 恢复：设置 ②「从 progress.json 导入」选这个文件即可。

## 五、隐私边界

**已做到**：

- 内容加密：本地文件与线上文件搜索「马原 / 新思想 / 毛中特 / 史纲 / 思修 / 当代 / 考研 / 政治 / 模板」等关键词均为 **0 命中**。
- 锁定页无元信息：`<title>` 为「笔记」，无 description/og，`robots` 为 `noindex,nofollow,noarchive,nosnippet,noimageindex`。
- 路径不表意：`/k7m2q/`；旧 `/zzbs/` 已覆盖为同一份锁定版，不再有明文页。
- 同步不传正文：只有进度位掩码与日期；频道号由口令派生，不含科目、考试等词。
- 外链 0：运行时没有任何第三方脚本/字体/图片请求；唯一的联网行为是点「同步」时的 ntfy 请求（开自动同步时才会定时发）。
- 锁定页不显示频道号，频道只在解锁成功后计算。

**做不到 / 仍存在的风险**：

- 4 位口令可被穷举，这是当前配置的硬伤；要保密就用 ⑤ 换成强口令并替换线上文件。
- 知道口令的人也能推出频道，能看到你的进度（只有进度，没有正文）。
- 同步内容在 ntfy 服务器保留 12 小时，服务端理论上可见（内容是进度，不是正文）。
- GitHub Pages 与网络链路仍可能记录"谁访问过这个地址"，但看不到内容。
- **git 历史里仍有改造前的明文版本**（旧提交的 `zzbs/index.html`）。要历史级干净只能强制推送重写历史，属破坏性操作，未执行；GitHub 端旧 commit 还可能通过 fork/缓存/镜像残留。最稳是删仓重建。

## 六、页面功能（解锁后）

- **页眉 56px**：只留标题「笔记」、同步状态点、「同步」按钮、「☰」菜单；搜索、进度条、仪表盘、筛选、自动同步开关全收进点开的折叠面板（默认收起，往下滚动自动收起）。
- 顶部仪表盘：今日待复习、今日新背配额、已掌握、连续打卡。
- 筛选：5 个科目、只看未掌握 / 只看今日到期 / 只看已掌握；搜索支持篇号、科目、触发词。
- 卡片上 D1 D2 D4 D7 D14 D30 冲刺节点，逐节点打勾，7 个全勾算「已掌握」。
- 单篇三模式：故事（可折叠）、原文（逐字）、自测（关键词变 ▢，点一下显形）。
- 8 分钟默写倒计时；单篇打印（A4 单页）；快捷键 ←/→ 切篇、空格换模式、Esc 关闭。
- 进度存 `localStorage`（键名 `nb_progress_v3`），按"浏览器 + 打开方式"隔离。
